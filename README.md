# Finn // Hallaka — Neon City

A personal portfolio with a cyan and magenta city background, mobile app projects, and a short introduction.

Live site: https://hallaka01.github.io

## Local development

Requires Python 3.9+, Node.js, just, and Lefthook. No application dependencies or backend are needed.

- just setup: install the Git hooks.
- just dev: preview at http://127.0.0.1:8767.
- just check: validate files, links, assets, and JavaScript syntax.
- just test: run HTTP and navigation smoke tests.

GitHub Actions validates changes and deploys the site directory to GitHub Pages. Project specifications and task status live in docs/.

The YGO Scanner screenshots use fictional demo cards; the scanner preview is simulated. The portfolio does not distribute the private application or official card artwork. See NOTICE.md for usage rights.
