# Neon City portfolio

## Purpose

Give Finn // Hallaka a personal portfolio with the full-page cyberpunk atmosphere that GitHub profiles cannot provide. Publish at https://hallaka01.github.io. The GitHub profile README is a single clickable banner; the portfolio contains the introduction, projects, and toolbox.

## Visitor experience

1. Meet Finn through a short English introduction over an original cyan and magenta city background.
2. Explore the YGO Scanner showcase and Finn's frontend contributions to HSMWmobil.
3. Read a short toolbox and follow direct project resources for screenshots, examples, or the HSMWmobil team.

The website is the main presentation destination. Avoid generic calls to return to the GitHub profile; repository links should lead to a specific resource.

## Scope

- One responsive page with persistent city scenery, clear typography, restrained neon accents, and subtle motion.
- Local images and static content; fictional YGO demo screenshots only.
- Keyboard navigation, reduced-motion support, working mobile navigation, and a useful 404 page.
- Deployment through GitHub Pages in the account's dedicated public repository.

## Non-goals

No authentication, database, contact form, analytics, invented achievements, private source code, personal contact information, or third-party app screenshots.

## Acceptance

All local checks pass. Review desktop and narrow layouts, exercise navigation and links, verify the public deployment and profile link, and keep the existing apps unchanged.
